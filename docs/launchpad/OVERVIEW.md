# PONS launchpad overview

PONS launches and explores fixed-supply tokens on Robinhood Chain.

## Published features

- **Fixed supply:** launched tokens are presented as fixed-supply assets.
- **Uniswap market:** the launch form identifies Uniswap as the trading venue and ETH as the pair asset.
- **Locked liquidity:** the launch summary displays liquidity as locked.
- **Graduation:** launches progress toward a displayed `4.2 ETH` target.
- **Developer buy:** creators may optionally buy tokens during launch.
- **Creator wallet:** proceeds can use the connected wallet or another EVM address.
- **Non-custodial transactions:** PONS does not hold user assets or submit transactions without wallet approval.

## Public interface areas

- **Explore:** discover tokens progressing toward graduation.
- **Create:** configure and submit a new launch.
- **Token page:** inspect and trade a specific launched token.
- **Profile:** view wallet-related launchpad activity where available.

Interface data may be indexed and can lag on-chain state. Execution-critical values should be confirmed in the wallet and, when possible, directly on-chain.
