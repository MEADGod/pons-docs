# Graduation

PONS presents launches as progressing toward graduation on Robinhood Chain. The current public launch form displays a graduation target of `4.2 ETH`.

## What the interface confirms

- Tokens can be explored while they are still progressing toward graduation.
- The launch summary displays the current target.
- Launch liquidity is displayed as locked.

## What is not publicly specified

The reviewed interface does not publish the exact on-chain graduation calculation, event signature, threshold getter, or state transition behavior. Do not infer graduation from market capitalization alone or assume that it migrates liquidity.

Integrators should treat the interface progress indicator as display data until PONS publishes a verified contract event or getter. Reconfirm the target at launch time because configuration can change.
