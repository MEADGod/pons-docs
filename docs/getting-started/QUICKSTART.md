# Quickstart

## For creators

1. Open <https://pons.family/launchpad/create>.
2. Connect an EVM wallet to Robinhood Chain.
3. Enter the token name, ticker, description, and image.
4. Optionally add community links.
5. Optionally enter a developer buy amount.
6. Leave the creator wallet empty to use the connected wallet, or provide another valid address.
7. Review the displayed launch fee, graduation target, liquidity status, and transaction preview.
8. Confirm the transaction in the wallet.
9. Share the deployed token contract address as the canonical identifier.

## For traders

1. Obtain the token contract address from a trusted source.
2. Confirm that the wallet is connected to Robinhood Chain.
3. Check the token page, Uniswap market, liquidity, price impact, and holder distribution.
4. Review the exact input, output, slippage, recipient, and gas before signing.

## For integrators

Use standard Robinhood Chain JSON-RPC and ERC-20/Uniswap interfaces for verified on-chain data. PONS does not currently publish a complete ABI and deployment registry in the reviewed public interface, so do not infer protocol contracts from token names, UI labels, or unverified third-party data.
