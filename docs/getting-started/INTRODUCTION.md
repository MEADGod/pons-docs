# Introduction

PONS is a token launchpad for Robinhood Chain. It provides an interface to launch and explore fixed-supply tokens while keeping transaction approval in the user's wallet.

## What PONS provides

- A launch form for token metadata and creator settings.
- An optional developer buy during launch.
- A configurable creator wallet.
- A Uniswap market paired with ETH.
- A displayed graduation target and locked launch liquidity.
- Explore and token pages for discovering launched assets.

## Non-custodial model

PONS does not custody assets. A connected wallet constructs, reviews, and submits each transaction. Users remain responsible for the selected network, destination contracts, values, gas, approvals, and final confirmation.

## What a PONS launch does not guarantee

A token appearing on PONS is not proof that it is safe, valuable, audited, or endorsed. Locked launch liquidity does not eliminate smart-contract, concentration, market, wallet, chain, or third-party liquidity risk.
