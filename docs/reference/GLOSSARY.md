# Glossary

- **Creator wallet:** connected or custom EVM address designated to receive creator fees and developer-buy tokens.
- **Developer buy:** optional creator purchase included in the launch flow.
- **DEX:** decentralized exchange.
- **Fixed supply:** token supply intended not to increase after creation; verify the implementation on-chain.
- **Graduation:** PONS launch milestone currently displayed with a `4.2 ETH` target.
- **Launch fee:** amount charged to create a token; currently displayed as `0.0005 ETH`.
- **Liquidity lock:** mechanism intended to prevent withdrawal of the launch liquidity.
- **Non-custodial:** the interface does not hold user assets; users sign transactions from their wallets.
- **Pair asset:** asset traded against the launched token, displayed as ETH by PONS.
- **Price impact:** change in execution price caused by a trade relative to available liquidity.
- **Slippage:** difference between the quoted and permitted execution price.
- **Ticker:** short token symbol, commonly displayed with a `$` prefix.
