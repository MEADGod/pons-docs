# FAQ

## What is PONS?

PONS is a non-custodial launchpad for launching and exploring fixed-supply tokens on Robinhood Chain.

## Which chain does it use?

Robinhood Chain, chain ID `4663`, with ETH as the displayed native and pair asset.

## What is the launch fee?

The public creation page currently displays `0.0005 ETH`. Confirm the live value before signing.

## What is the graduation target?

The interface currently displays `4.2 ETH`. The exact on-chain calculation is not published in the reviewed pages.

## Is liquidity locked?

The launch summary displays liquidity as locked. Verify the locker contract and withdrawal properties on-chain before relying on that statement programmatically.

## What is a developer buy?

An optional ETH amount used to buy the launched token during the launch flow. Resulting tokens are directed to the creator wallet described by the form.

## Which wallet receives creator proceeds?

The connected wallet by default. A different creator wallet can be entered in Advanced settings.

## Are links required?

No. The description, X profile, Telegram community, and website are presented as optional fields.

## How do I identify the genuine token?

Use the deployed contract address on Robinhood Chain. Names and tickers can be duplicated.

## Does PONS custody assets?

No. The interface states that the user's wallet submits every transaction.

## Is every listed token safe?

No. A PONS launch is not an audit, endorsement, or guarantee of value.
