## Contract addresses

The reviewed PONS interface does not publish a complete official deployment registry for its launch factory, token implementation, liquidity locker, fee distributor, Uniswap contracts, or deployment blocks.

Do not copy addresses from another protocol or infer them from UI text. Before production use, PONS should publish checksummed addresses, verified source links, ABIs, deployment transactions, deployment blocks, and upgrade/admin information.
